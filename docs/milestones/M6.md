### 2. 材料快照（library.py，新拆出 fetch.py）

```
fetch_material(id) --not studying--> refresh: source -> split -> sections.json
                   |                 (+ source_hash, split_version, snapshot_at)
                   +--studying-----> keep the snapshot; if the source changed, say so in the outline
read_section / render_lesson / update_progress  --> always read the snapshot
fetch_material(id, refresh=true) --> new snapshot; progress mapped to the page with the same title
```

### 1. 按角色配置模型（问题 5）

- **怎么配**：环境变量 `LOOPBACK_<角色>_MODEL`，例如 `LOOPBACK_TEACHER_MODEL`；没设就用 `MODEL_ID`。`Settings` 启动时一次读出所有角色的模型，用 `settings.model_for("teacher")` 取某个角色该用的模型。
- **代码里写死**：`AgentSpec` 加一个 `model` 字段，可以在代码里给某个角色固定一个模型，比如以后的子 agent。
- **优先级**：`AgentSpec.model` 最高，其次是 `LOOPBACK_<角色>_MODEL`，最后是 `MODEL_ID`。
- **loop 和请求**：`build_request` 不再直接读 `settings.model`，改由 loop 传入这个角色的模型。“实际服务的模型和请求的不一致”这条告警，也改成和这个角色的模型比。
- **其他用到模型的地方**：启动时打印的模型、会话 meta、evals 的 manifest 和试验 meta，都改成角色的模型。`evals.run --model` 要同时覆盖教师的模型，否则 `.env` 里的 `LOOPBACK_TEACHER_MODEL` 会悄悄盖过命令行参数。
- **约束**：一个会话只用一个模型。REPL 每次启动都开新会话，每个角色也有自己的会话，所以换模型不会把两个模型的 thinking 混进同一段历史。
- **这次不做**：不同角色走不同服务商（比如助教用 DeepSeek）。那需要按角色配 client 和 Profile。
- **文档**：`.env.example` 加上说明。

### 2. 反馈分两级（问题 9）

- **每页打分**：讲完一页后提示一句：“给这一页打分：回 next 1-5，可以加一句”。直接 `next` 就是跳过，不记分。
  - REPL：harness 直接解析 `next 4 太长了`，先记分，再照常讲下一页。这条输入不经过模型；讲完一页后也不再停下来专门等你打分。
  - Claude Code：`next_step` 加两个可选参数 `rating`、`note`。教师看到 `next 4 太长了`，就调用 `next_step(rating=4, note="太长了")`，由代码记分。这句提示写在 `/learn` skill 里。
- **每篇打分**：讲完总结后问一句：“这篇整体几分？最有用和最没用的是哪一页？”
  - REPL：输入 `/rate 4 一句话`；也可以直接告诉教师，由教师调用 `record_feedback(level=article)`。
  - Claude Code：由教师调用 `record_feedback(level=article)`。
- **feedback.jsonl 的每条记录**：

  | 字段 | 含义 |
  |---|---|
  | `level` | page 或 article |
  | `section` | 页号，篇级为空 |
  | `page_title` | 页的标题 |
  | `snapshot_at` | 快照时间 |
  | `score` | 1–5 分 |
  | `note` | 附带的一句话 |
  | `source` | 谁记的：repl、next_step 或 teacher |
  | `front_end` | repl 或 claude-code |
  | `prompt_hash` | 教师 prompt 的版本，两个前端都记 |
  | `model` | REPL 记请求的模型；Claude Code 拿不到，留空 |

  旧记录没有 `level` 字段，按页级处理。
- **页的身份**：用“页标题 + 快照时间”。这样以后快照换了，也能对上是哪一页。
- **隐式信号**：每页停留多久、问了几个旁支问题，放到 M6e 从对话日志里算。
